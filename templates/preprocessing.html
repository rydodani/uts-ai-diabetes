⚙️ Kriteria 2 Soal UTS

Preprocessing Data & Pembagian Data (Data Splitting)

Rangkaian prosedur penyiapan data mentah, penanganan anomali nilai nol biologis, serta pembagian partisi data latih dan uji secara terkontrol.

🔄 4 Tahapan Utama Preprocessing Data

Pipeline Data AI

1. Penyesuaian Format & Pemberian Header Kolom

Dataset mentah dari repositori UCI/Kaggle disimpan tanpa baris nama kolom. Sistem melakukan penyesuaian dengan menyematkan 8 nama fitur prediktor (Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age) dan 1 label target (Outcome).

2. Deteksi Anomali Nilai 0 Fisiologis

Mendeteksi nilai 0 yang tidak masuk akal secara medis pada 5 atribut: Glukosa (5 baris), Tekanan Darah (35 baris), Tebal Kulit (227 baris), Insulin (374 baris), dan BMI (11 baris). Nilai 0 ini diidentifikasi sebagai data hilang (missing data) yang belum tercatat saat pemeriksaan laboratorium.

3. Penanganan Data (Baseline vs Imputasi Median)

Sistem mengimplementasikan dua skenario:
• Model Baseline: Mempertahankan nilai asli sesuai eksperimen jurnal JDMIS 2026.
• Model Optimasi: Mengganti nilai 0 dengan nilai Median yang dihitung hanya dari data latih untuk menghindari data leakage (kebocoran informasi data uji).

4. Pembagian Data (Hold-out 80:20)

Dataset 768 baris dibagi menggunakan metode hold-out dengan proporsi 80% data latih (614 sampel) untuk proses pembelajaran pohon dan 20% data uji (154 sampel) untuk evaluasi performa objektif.
